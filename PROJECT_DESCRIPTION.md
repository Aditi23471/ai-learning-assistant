AI Learning Assistant

Project Type: Beginner Python Project
Field: Computer Science and Artificial Intelligence

About the Project

AI Learning Assistant is an interactive educational program developed using Python. It allows users to explore basic topics in Python, Artificial Intelligence and Mathematics.

Key Features

* Interactive topic selection
* Educational explanations
* Five-question quiz
* Automatic answer checking
* Score and percentage calculation

Technologies Used

* Python
* Conditional statements
* User input
* String methods
* Basic programming logic

My Motivation

I am interested in Computer Science and Artificial Intelligence. I created this project to develop my programming skills and understand how technology can make learning more interactive and accessible.

Future Development

I plan to add more learning topics, save student progress and explore genuine AI integration.

My Learning Outcome

Through this project, I practised writing Python code, using conditional statements, debugging errors and building an interactive program.
